📦 Variables & Data Types

Think of a variable as a magic box. You give it a name, tell C what kind of stuff fits inside, and then store data in it for later.

Data Types: The Shape of the Box

In C, you must be specific. You can't put a word in a number box!

Type Usage Example
int Whole Numbers 42, -7
float Decimals 3.14
double / long float Large Decimals 3.14159265
long Large Whole Numbers 100000L
char Single Character 'A'
char[] Text / Strings "Hello"

Declaring a Variable

C Pattern 
int age;          // Declare (Empty box)
age = 20;         // Initialize (Put value in)

float gpa = 3.85; // Do both at once!
💡
Pro Tip: Every statement in C must end with a ;. It's like a full stop at the end of a sentence.

📥 Input & Output

To talk to your user, you use scanf() to listen and printf() to speak.

Reading Input

input.c 
int age;
printf("Enter age: ");
scanf("%d", &age); // & means "address of"
⚠️
Don't forget the & before the variable name in scanf! (Except for strings).
