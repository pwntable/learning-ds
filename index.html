📦 Lesson 1: Variables & Data Types

⏱ ~20 minutes  |  Level: Complete Beginner

A variable is a named box in memory where your program stores information.

1 Data Types in C

TypeStoresExampleSize
intWhole numbers42, -5, 04 bytes
floatDecimal numbers3.14, 2.54 bytes
doubleMore precise decimals3.141592658 bytes
charOne character'A', 'z'1 byte
char[]Text (string)"Hello"varies

2 How to Declare a Variable

Declaring = telling C "I need a box of this type, and call it this name".

// Pattern: dataType variableName; int age; float price; char letter; char name[50]; // String that holds up to 50 characters

3 Initialize (Put a Value In)

int age = 20; float gpa = 3.85; char grade = 'A'; char name[50] = "Khai";

4 Two Ways to Assign

// Method 1: Declare first, assign later int score; score = 95; // Method 2: Declare and assign at same time int score = 95;
⚠️ Important: Every statement in C must end with a semicolon ; — think of it like a full stop at end of a sentence.
💡 Tip: Variable names cannot have spaces. Use underscore: student_id or camelCase: studentId

🎯 Lesson 2: Your First C Program

⏱ ~20 minutes

The Basic Structure

Every C program must have this skeleton:

#include <stdio.h> // Include the printing library int main() { // Program starts here // Your code goes in here return 0; // Program finished OK }

1 Hello World!

#include <stdio.h> int main() { printf("Hello, World!\n"); return 0; }
Output:
Hello, World!
📌 \n means "new line" — it moves the cursor to the next line after printing.

2 Format Specifiers (Print Variables)

Use placeholders inside printf() to print variable values:

PlaceholderTypeExample
%dintprintf("%d", 42); → 42
%ffloatprintf("%f", 3.14); → 3.140000
%.2ffloat (2 decimal)printf("%.2f", 3.14); → 3.14
%ccharprintf("%c", 'A'); → A
%sstringprintf("%s", "Hi"); → Hi

3 Print Multiple Variables

#include <stdio.h> int main() { char name[50] = "Khai"; int age = 20; float gpa = 3.85; printf("Name : %s\n", name); printf("Age : %d\n", age); printf("GPA : %.2f\n", gpa); return 0; }
Output:
Name : Khai Age : 20 GPA : 3.85

📥 Lesson 3: Input & Output

⏱ ~15 minutes

Use scanf() to read input from the user's keyboard.

1 Read an Integer

#include <stdio.h> int main() { int age; printf("Enter your age: "); scanf("%d", &age); // & means "address of" — where to store value printf("You are %d years old!\n", age); return 0; }
Sample Run:
Enter your age: 20 You are 20 years old!
⚠️ Always put & before the variable in scanf! Except for strings (char arrays) — they don't need &.

2 Read a String

#include <stdio.h> int main() { char name[50]; printf("Enter your name: "); scanf("%s", name); // No & for strings! printf("Hello, %s!\n", name); return 0; }

3 Full Profile Program

#include <stdio.h> int main() { char name[50]; int age; float cgpa; printf("Enter your name: "); scanf("%s", name); printf("Enter your age: "); scanf("%d", &age); printf("Enter your CGPA: "); scanf("%f", &cgpa); printf("\n--- My Profile ---\n"); printf("Name : %s\n", name); printf("Age : %d\n", age); printf("CGPA : %.2f\n", cgpa); return 0; }
Sample Run:
Enter your name: Khai Enter your age: 20 Enter your CGPA: 3.85 --- My Profile --- Name : Khai Age : 20 CGPA : 3.85

🔄 Lesson 5: Loops

⏱ ~25 minutes

Loops repeat code without you writing it multiple times.

1 For Loop (when you know how many times)

#include <stdio.h> int main() { for (int i = 1; i <= 5; i++) { printf("Count: %d\n", i); } return 0; }
Output:
Count: 1 Count: 2 Count: 3 Count: 4 Count: 5
📌 For loop breakdown:
• int i = 1 → start at 1
• i <= 5 → keep going while i is 5 or less
• i++ → add 1 to i each time (same as i = i + 1)

2 Times Table with For Loop

#include <stdio.h> int main() { int num = 7; printf("Times table of %d:\n", num); for (int i = 1; i <= 10; i++) { printf("%d x %d = %d\n", num, i, num * i); } return 0; }

3 While Loop (repeat while condition is true)

#include <stdio.h> int main() { int count = 5; while (count > 0) { printf("%d...\n", count); count--; // count = count - 1 } printf("Blastoff!\n"); return 0; }
Output:
5... 4... 3... 2... 1... Blastoff!

4 Do-While Loop (runs at least once)

#include <stdio.h> int main() { int choice; do { printf("\n1. Say Hello\n2. Exit\n"); printf("Choice: "); scanf("%d", &choice); if (choice == 1) { printf("Hello!\n"); } } while (choice != 2); // Keep looping unless user picks 2 printf("Goodbye!\n"); return 0; }

5 Nested Loops — Star Pattern

#include <stdio.h> int main() { for (int row = 1; row <= 4; row++) { for (int col = 1; col <= 4; col++) { printf("* "); } printf("\n"); } return 0; }
Output:
* * * * * * * * * * * * * * * *

📋 Lesson 6: Arrays

⏱ ~20 minutes

An array stores many values of the same type in one variable — like a numbered list of boxes.

1 Declare and Initialize

// int arrayName[size] = {values}; int scores[5] = {90, 85, 92, 78, 88}; // Access using index (starts at 0, not 1!) printf("%d\n", scores[0]); // 90 (first) printf("%d\n", scores[2]); // 92 (third) printf("%d\n", scores[4]); // 88 (last)
⚠️ Arrays start at index 0! A 5-element array has indices 0, 1, 2, 3, 4.

2 Loop Through Array

#include <stdio.h> int main() { int scores[5] = {90, 85, 92, 78, 88}; for (int i = 0; i < 5; i++) { printf("Test %d: %d\n", i + 1, scores[i]); } return 0; }
Output:
Test 1: 90 Test 2: 85 Test 3: 92 Test 4: 78 Test 5: 88

3 Find Sum and Average

#include <stdio.h> int main() { int numbers[5] = {10, 20, 30, 40, 50}; int sum = 0; for (int i = 0; i < 5; i++) { sum = sum + numbers[i]; } printf("Sum : %d\n", sum); printf("Average : %.2f\n", (float)sum / 5); return 0; }
Output:
Sum : 150 Average : 30.00

4 Find Maximum Value

#include <stdio.h> int main() { int nums[6] = {15, 48, 32, 92, 61, 25}; int max = nums[0]; // Assume first is the biggest for (int i = 1; i < 6; i++) { if (nums[i] > max) { max = nums[i]; // Found bigger, update max } } printf("Maximum: %d\n", max); return 0; }
Output:
Maximum: 92

5 String Arrays

#include <stdio.h> int main() { char fruits[3][20] = {"Apple", "Banana", "Cherry"}; for (int i = 0; i < 3; i++) { printf("%d. %s\n", i + 1, fruits[i]); } return 0; }
Output:
1. Apple 2. Banana 3. Cherry

🏗️ Lesson 7: Struct & Typedef

⏱ ~20 minutes

A struct groups different types of data under one name. Like a form with multiple fields.

1 Define a Struct

struct Student { int id; char name[50]; float cgpa; int semester; };

2 Create and Use a Struct

#include <stdio.h> #include <string.h> // Needed for strcpy() struct Student { int id; char name[50]; float cgpa; }; int main() { struct Student s1; // Declare a student s1.id = 12345; strcpy(s1.name, "Khai"); // Assign text to char array s1.cgpa = 3.85; printf("ID : %d\n", s1.id); printf("Name : %s\n", s1.name); printf("CGPA : %.2f\n", s1.cgpa); return 0; }
Output:
ID : 12345 Name : Khai CGPA : 3.85
📌 Use dot notation s1.name to access fields inside a struct.

3 Typedef — Shorter Name

typedef lets you skip writing struct every time:

// Before typedef → must write "struct Student" every time struct Student s1; // With typedef → just write "Student" typedef struct { int id; char name[50]; float cgpa; } Student; // "Student" is now a type Student s1; // Clean! No "struct" needed

4 Array of Structs

#include <stdio.h> #include <string.h> typedef struct { int id; char name[50]; float cgpa; } Student; int main() { Student students[3]; students[0].id = 101; strcpy(students[0].name, "Khai"); students[0].cgpa = 3.85; students[1].id = 102; strcpy(students[1].name, "Ali"); students[1].cgpa = 3.65; students[2].id = 103; strcpy(students[2].name, "Zara"); students[2].cgpa = 3.92; printf("%-5s %-15s %-5s\n", "ID", "Name", "CGPA"); printf("-------------------------------\n"); for (int i = 0; i < 3; i++) { printf("%-5d %-15s %.2f\n", students[i].id, students[i].name, students[i].cgpa); } return 0; }
Output:
ID Name CGPA ------------------------------- 101 Khai 3.85 102 Ali 3.65 103 Zara 3.92
