📦 Variables & Data Types

Think of a variable as a magic box. You give it a name, tell C what kind of stuff fits inside, and then store data in it for later.

Data Types: The Shape of the Box

In C, you must be specific. You can't put a word in a number box!

Type Usage Example
int Whole Numbers 42, -7
float Decimals 3.14
double / long float Large Decimals 3.14159265
long Large Whole Numbers 100000L
char Single Character 'A'
char[] Text / Strings "Hello"

Declaring a Variable

1 · Declare only (no value yet) 
int    age;          // whole number  — value is garbage until set!
float  price;        // decimal (6-7 significant digits)
double pi;           // decimal (15-16 significant digits)
char   grade;        // single character  e.g. 'A'
long   population;   // large whole number
2 · Declare + Initialize (recommended) 
int    age        = 20;           // integer
float  price      = 5.50f;        // float  (note the 'f' suffix)
double pi         = 3.14159265;  // double — higher precision
char   grade      = 'A';          // single char — use single quotes
long   population = 8000000000L; // long   (note the 'L' suffix)
3 · String (array of chars) 
char name[20];                 // empty string buffer (20 chars max)
char city[10] = "Johor";       // initialized string — double quotes
char msg[]  = "Hello, World!";  // compiler counts the size for you
4 · Unsigned & Short (size variants) 
unsigned int   score = 95;    // only positive (0 to ~4 billion)
short          small = 32767; // smaller int (-32768 to 32767)
unsigned char  byte  = 255;   // 0–255, often used for raw bytes
5 · Constants (value cannot change) 
const float  TAX_RATE = 0.06f;  // const — locked after declaration
const int    MAX_SIZE = 100;     // changing this will cause a compile error

// Preprocessor constant (no type, no semicolon inside #define)
#define PI 3.14159
6 · Multiple variables on one line 
int x = 1, y = 2, z = 3;  // declare & init 3 ints at once
float a, b, c;              // declare 3 floats (all uninitialized)
💡
Pro Tip: Every statement in C must end with a ;. It's like a full stop at the end of a sentence.

📥 Input & Output

To talk to your user, you use scanf() to listen and printf() to speak.

Reading Input

input.c 
int age;
printf("Enter age: ");
scanf("%d", &age); // & means "address of"
⚠️
Don't forget the & before the variable name in scanf! (Except for strings).

🔗 Linked Lists

A chain of nodes where each node points to the next one in memory. Each Node stores data and a next pointer — forming a dynamic chain. 

struct Node {
    int data;
    struct Node* next;
};
